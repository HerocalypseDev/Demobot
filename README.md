# Demobot

An all-in-one Discord bot built with Discord.js v14 and Node 24.

Work in progress. Planned modules: tickets, verification, role menus, welcome messages, moderation with logs, automod, giveaways, suggestions, reminders, applications, an embed builder and a staff dashboard.

## Requirements

- Node 24 or newer
- A Discord application with a bot token

## Setup

1. Copy `.env.example` to `.env` and fill in `DISCORD_TOKEN` and `CLIENT_ID`.
2. `npm install`
3. `npm run deploy` to register slash commands.
4. `npm start`
